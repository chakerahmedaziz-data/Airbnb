# Airbnb

Projet de transformation des données brutes d'Airbnb

Il contient les annonces (listings), les avis voyageurs (reviews) et le calendrier de disponibilité (calendar)

Ce projet est réalisé en utilisant Databricks



\## Structure du projet



| Dossier | Rôle |

|---|---|

| `src/` | Code réutilisable des transformations |

| `notebooks/` | Exploration et analyses ponctuelles |

| `pipelines/` | Définition des pipelines Lakeflow |

| `resources/` | Configuration des jobs et du déploiement |

| `tests/` | Tests automatisés |

| `docs/` | Documentation |



Le détail de l'architecture et les conventions de nommage sont dans \[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
